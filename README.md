# EdSarah Computer Student Grade Book

## Overview

This project is a console-based Student Gradebook application written in Java.
It was built to demonstrate my understanding of core Java language features
including variables, expressions, conditionals, loops, functions, classes,
the Java Collection Framework, and file input/output.

The purpose of this software is to provide a simple yet complete system for
managing student records and their grades. Users can add, remove, update,
and search for students, assign grades, view class statistics, and persist
all data to a text file so it is retained between sessions.

[Software Demo Video](http://youtube.link.goes.here)

## Development Environment

- **IDE:** Visual Studio Code with the Extension Pack for Java
- **JDK:** OpenJDK 17 (or later)
- **Build Tool:** None (plain Java with `javac` / `java`)
- **Language:** Java
- **Libraries Used:** `java.util` (ArrayList, HashMap, Scanner, List, Map),
  `java.io` (File, FileWriter, PrintWriter, BufferedReader, FileReader)
